# TalentMatrix AI - Pre-Employment Assessment System

Aplikasi web HR Assessment System untuk penilaian pelamar kerja berbasis DISC, MBTI, dan IQ dengan scoring engine otomatis & export PDF.

## Cara Deploy ke Vercel (1 Menit):

### Cara 1: Menggunakan GitHub + Vercel Dashboard (Paling Mudah)
1. Ekstrak zip project ini.
2. Buat repository baru di GitHub (misal: `talentmatrix-app`).
3. Push kode ini ke repository GitHub Anda.
4. Buka [https://vercel.com](https://vercel.com) dan login.
5. Klik **"Add New Project"** -> Import repository GitHub Anda.
6. Klik **"Deploy"** (tanpa perlu ubah konfigurasi apa pun).
7. Selesai! Web Anda akan langsung aktif dengan URL resmi (contoh: `talentmatrix-app.vercel.app`).

### Cara 2: Menggunakan Vercel CLI
```bash
npm install -g vercel
cd talentmatrix-vercel-app
vercel
```
